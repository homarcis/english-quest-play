# English Quest

A cozy pixel-art game for practising English sentence structure: build sentences, fix mistakes, match ideas and handle real conversations, step by step.

**Play:** https://homarcis.github.io/english-quest-play/

- Works in the browser on phones and computers; no account needed.
- Your progress is saved only in your own browser.
- Tap anywhere to start the music; turn music and sound effects off in **Menu**.

Art by Homar Cisneros (made with ChatGPT); sound is CC0.
